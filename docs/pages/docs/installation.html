Installation

Download the Aurora CSS files and add them to your project.

1. Folder Structure

Place the Aurora CSS files inside your project.

css/
├─ reset.css
├─ globals.css
├─ classes.css
└─ themes.css

js/
└─ aurora.js // Optional

2. Import the Aurora files

Import the Aurora CSS files into your HTML document.

<link rel="stylesheet" href="./css/reset.css">
<link rel="stylesheet" href="./css/globals.css">
<link rel="stylesheet" href="./css/classes.css">
<link rel="stylesheet" href="./css/themes.css">
Note: Aurora CSS works without JavaScript. Import aurora.js only if you need interactive components such as Navbar, Sidebar, Panel and Theme Selector.
