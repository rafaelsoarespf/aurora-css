Utilities

Utility classes for spacing, alignment, sizing, and layout adjustments.

Position

Position elements inside a parent element.

.position-t .position-r .position-b .position-l .position-tl .position-tr .position-bl .position-br 
<div class="card">
  <span class="badge position-tr">New</span>
</div>
Position classes require the parent element to use position: relative (or another positioned value).

Center

.center centers content horizontally and vertically inside a container.

Border

Utility classes for adding and customizing borders.

Class Description
.border Adds a 1px border using --color-border.
.border-none Removes all borders.
.border-top Adds a top border.
.border-right Adds a right border.
.border-bottom Adds a bottom border.
.border-left Adds a left border.
.border-accent Changes the border color to --color-accent. Use together with a border utility.
Default Border
<div class="border">Default Border</div>
Accent Border
<div class="border border-accent">Accent Border</div>
