Aurora CSS

Learn how to use Aurora CSS, explore its components, and build consistent interfaces with the framework.

Installation

Installation

Download the Aurora CSS files from the repository and add thecss folder to your project.

css/
├─ reset.css
├─ globals.css
├─ classes.css
└─ themes.css

Then import the Aurora stylesheets:

<link rel="stylesheet" href="./css/reset.css">
<link rel="stylesheet" href="./css/globals.css">
<link rel="stylesheet" href="./css/classes.css">
<link rel="stylesheet" href="./css/themes.css">
Themes

Themes

Customize the appearance of your application by setting the data-theme attribute to one of Aurora's built-in themes.

Usage 
<body data-theme="aurora-light">

Theme Selector

Use this example to add a theme selector that lets users switch between Aurora's built-in themes.

HTML 
<select class="theme-selector">
  <option value="aurora-light">Aurora Light</option>
  <option value="aurora-dark">Aurora Dark</option>
  <option value="light">Light</option>
  <option value="dark">Dark</option>
  <option value="light-teal">Light Teal</option>
  <option value="dark-teal">Dark Teal</option>
  <option value="coffee">Coffee</option>
  <option value="paper">Paper</option>
  <option value="neumorphism">Neumorphism</option>
  <option value="glass">Glass</option>
  <option value="forest">Forest</option>
  <option value="nord">Nord</option>
  <option value="sakura">Sakura</option>
  <option value="gold">Gold</option>
</select>
TypeScript 
const selectors=document.querySelectorAll<HTMLSelectElement>('.theme-selector');
const savedTheme=localStorage.getItem('aurora-theme');

if(savedTheme){
  document.body.setAttribute('data-theme',savedTheme);
  selectors.forEach(selector=>selector.value=savedTheme);
}

selectors.forEach(selector=>{
  selector.addEventListener('change',()=>{
    const theme=selector.value;

    document.body.setAttribute('data-theme',theme);
    localStorage.setItem('aurora-theme',theme);

    selectors.forEach(s=>s.value=theme);
  });
});
