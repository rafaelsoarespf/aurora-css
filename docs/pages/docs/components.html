Sidebar

Responsive sidebar for dashboards and application layouts. On mobile, use .sidebar__toggle to open and close the sidebar. 

<body class="sidebar-layout">
  <aside class="sidebar">

    <div class="sidebar__header">
      <h3>Logo</h3>
    </div>

    <nav class="sidebar__menu">
      <a href="#" class="active">Dashboard</a>
      <a href="#">Projects</a>
      <a href="#">Settings</a>
      <a href="#">Profile</a>
    </nav>

    <div class="sidebar__footer">
      <button class="btn size-full">Logout</button>
    </div>
  </aside>

  <main class="content">
    <button class="sidebar__toggle">☰</button>
    ...
  </main>

</body>

Layout: Wrap the page with .sidebar-layout. The sidebar occupies the left column, while the main content uses the .content container.
