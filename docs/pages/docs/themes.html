Themes

Themes

Apply, preview and customize Aurora CSS themes.

Apply a Theme

Apply one of the built-in Aurora CSS themes using the data-theme attribute. 

<body data-theme="aurora-light">

Theme Selector

Use the theme-selector class to let users switch between Aurora CSS themes. 

<select class="theme-selector">
  <option value="aurora-light">Aurora Light</option>
  <option value="aurora-dark">Aurora Dark</option>
  <option value="light">Light</option>
  <option value="dark">Dark</option>
  <option value="light-teal">Light Teal</option>
  <option value="dark-teal">Dark Teal</option>
  <option value="coffee">Coffee</option>
  <option value="paper">Paper</option>
  <option value="neumorphism">Neumorphism</option>
  <option value="glass">Glass</option>
  <option value="forest">Forest</option>
  <option value="nord">Nord</option>
  <option value="sakura">Sakura</option>
  <option value="gold">Gold</option>
  <option value="light-slate-mist">Light Slate Mist</option>
  <option value="dark-slate-mist">Dark Slate Mist</option>
</select>
Note: The Theme Selector requires aurora.js file.
